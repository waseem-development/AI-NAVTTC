Overview

This is the opening lecture of the Artificial Neural Networks (CS642) course. Despite the course title, Lecture 01 doesn't dive into neurons yet — instead it sets the stage by answering a more basic question: what is machine learning, and where does deep learning (and eventually ANNs) fit inside it? The lecture has five parts: Introduction, Applications, Data, Artificial Neural Network (as a concept, not yet in detail), and "How Deep is Deep?"

Why this matters: Every later lecture on perceptrons, weights, activation functions, and backpropagation builds on the vocabulary introduced here — "supervised learning," "features," "model," "deep learning," "depth." Getting comfortable with these now makes the rest of the semester much easier to follow.

Learning Objectives

Derived from lecture content

The slides don't list explicit objectives, so these are inferred from what the lecture actually covers:

  • Define machine learning and explain how it differs from traditional, explicitly-programmed software.
  • Identify common real-world application areas of machine learning (vision, marketing, search).
  • Describe the general machine learning pipeline: raw data → preprocessing → dimensionality reduction → model learning → testing → results.
  • Explain the "Database → Learner → Classifier" mental model of how a model is produced from data.
  • Define supervised learning as learning a mapping from labeled input-output pairs.
  • Define deep learning as a subfield of machine learning based on artificial neural networks (algorithms inspired by the brain).
  • Explain, informally, how "depth" (number of layers) is used to judge whether a network counts as "deep."

Big Picture

Before the details, it helps to see where this lecture sits inside the wider field:

What Is Machine Learning?

From your lecture

🟢 Simple Explanation

Normally, to make a computer do something, a programmer writes exact step-by-step instructions. Machine learning flips that: instead of telling the computer exactly what to do, you show it lots of examples, and it figures out the pattern itself.

🔵 Technical Explanation

Per the lecture: "Machine learning is an application of artificial intelligence (AI) that provides systems the ability to automatically learn and improve from experience without being explicitly programmed." It focuses on programs that can access data and use it to learn for themselves, rather than following a fixed, hand-written rule set.

Why Do We Need It?

Some tasks (like recognizing a face, understanding a sentence, or predicting whether an email is spam) are too complex, too variable, or too poorly understood for a human to write exhaustive rules for. Instead of hand-coding every rule, we let the system learn the rules from data.

Applications Mentioned in the Lecture

Computer Vision

Teaching machines to interpret images.

Image Processing

Manipulating and analyzing image data.

Marketing

Predicting customer behavior, targeting.

Search Engines

Ranking and retrieving relevant results.

Object Recognition

Identifying objects within images/video.

Face Recognition

Identifying/verifying people from images.

Supervised Learning

From your lecture

🟢 Simple Explanation

You show the computer pairs of "question and correct answer" — lots of them — and it learns a general rule for going from question to answer, so that later it can answer questions it has never seen.

🔵 Technical Explanation

Per the lecture: "Supervised learning is the machine learning task of learning a function that maps an input to an output based on example input-output pairs. It infers a function from labeled training data consisting of a set of training examples."

Why It Matters

Supervised learning is the setting that most introductory ANN material (including perceptrons and multi-layer networks trained with backpropagation) is built around: inputs go in, a known correct output is compared against the network's prediction, and the error is used to improve the network.

Symbol / Term Meaning Example
Input The example data given to the model An image, a set of features
Output / Label The known correct answer for that input "cat", "spam", a price
Training example One input-output pair (image of a cat, "cat")
Function The mapping the model is trying to learn image → label

Deep Learning

From your lecture

🟢 Simple Explanation

Deep learning is machine learning done with big, multi-layered neural networks — systems loosely modeled on how the brain's neurons connect to each other.

🔵 Technical Explanation

Per the lecture: "Deep Learning is a subfield of machine learning concerned with algorithms inspired by the structure and function of the brain called artificial neural networks." The "central goal of AI," per the slides, is to provide algorithms that can solve problems humans do intuitively and near-automatically but that are hard for computers — the running example given is interpreting the content of an image.

Why Do We Need It?

Traditional ML depends heavily on handcrafted features — a human decides in advance what patterns (edges, colors, shapes) the algorithm should look for. Deep learning instead lets the network learn its own features directly from raw data, layer by layer, from simple to abstract.

🔵 Key Idea

In the traditional pipeline, a human engineer designs the "Handcrafted Feature Extraction Algorithms" box. In deep learning, that box is replaced by several learned layers that automatically progress from simple features (edges) to intermediate features (corners) to abstract features (object parts) — this layer-by-layer abstraction is exactly why depth matters.

How Deep Is Deep?

From your lecture

The lecture poses this as an open, slightly philosophical question rather than handing down one strict rule — which is intentional, since "how deep counts as deep" is genuinely debated in the field.

"Convolutional Neural Network (CNN) is a type of deep learning algorithm. But suppose we had a CNN with only one convolutional layer – is a network that is shallow, but yet still belongs to a family of algorithms inside the deep learning camp considered to be 'deep'?"

The slides offer three rough heuristics for deciding whether something counts as "deep learning":

# Heuristic (from the lecture) Verdict
1 Are you using a specialized architecture — CNN, RNN, or LSTM? → Yes, you are performing deep learning
2 Does your network have depth > 2? → Yes, you are doing deep learning
3 Does your network have depth > 10? → Yes, you are performing very deep learning

Performance vs. Amount of Data

🔵 Why This Curve Matters

This is one of the main practical reasons deep learning became popular: with small datasets, hand-engineered features can actually beat deep networks. But as the amount of available data grows very large, deep networks keep improving while traditional pipelines top out — because deep networks can absorb and exploit far more information from data without a human needing to redesign the features.

Comparisons

Traditional Programming vs. Machine Learning

Aspect Traditional Programming Machine Learning
Rules Written explicitly by a programmer Learned automatically from data
Input to system Rules + data → output Data + desired output → rules (model)
Adapting to new patterns Requires rewriting code Requires retraining on new data
Best suited for Well-understood, well-specified problems Complex, hard-to-specify patterns (vision, language)

Traditional Feature Extraction + ML vs. Deep Learning

Aspect Traditional ML Pipeline Deep Learning
Feature extraction Handcrafted by a human engineer Learned automatically, layer by layer
Feature complexity Fixed set, human-designed Progresses simple → intermediate → abstract
Performance with little data Often better Often worse (needs more data)
Performance with lots of data Plateaus Keeps improving

⚠️ Common Beginner Mistakes

Mistake: Thinking "not explicitly programmed" means "no code is written"

Why people make it: The phrase sounds like the system writes itself with no human involvement.

Correct understanding: Code is still written — to define the model architecture and the learning algorithm. What's learned from data are the parameters (like weights), not the entire program.

Mistake: Treating "AI," "machine learning," and "deep learning" as interchangeable

Why people make it: They're often used loosely in the media.

Correct understanding: Per this lecture's own hierarchy: AI is the broadest field, machine learning is a subfield of AI focused on learning from data, and deep learning is a subfield of machine learning based specifically on (deep) artificial neural networks.

Mistake: Assuming "deep" has one universally agreed definition

Why people make it: Students expect a single precise threshold, like in math.

Correct understanding: The lecture explicitly frames this as an open question (the CNN example) and gives multiple, sometimes conflicting heuristics (architecture type vs. depth > 2 vs. depth > 10).

Mistake: Assuming deep learning is always better than traditional ML

Why people make it: Deep learning gets more hype and press coverage.

Correct understanding: The performance-vs-data graph shows traditional feature extraction + ML can outperform deep learning when data is limited. Deep learning's advantage shows up mainly at large data scale.

Concept Map

Glossary

Artificial Neural Network (ANN)
An algorithm inspired by the structure and function of the brain, used to implement deep learning.
Classifier / Classification Model
The output of a learner/inducer trained on a database — a model that assigns labels to new data. Intuition: the "trained brain" produced from a training set.
CNN (Convolutional Neural Network)
A type of deep learning architecture, mentioned in the lecture in the context of the "how deep is deep" question.
Deep Learning
A subfield of machine learning based on algorithms (artificial neural networks) inspired by the brain. Intuition: "big, layered neural nets."
Depth
Roughly, the number of layers in a neural network; used informally in the lecture to judge whether a network counts as "deep" or "very deep."
Dimensionality Reduction
A pipeline stage that reduces data to its most informative features via feature selection or projection.
Feature Extraction
Identifying informative attributes in raw data; done by hand in traditional ML, learned automatically in deep learning.
Induction Algorithm / Learner / Inducer
The algorithm that processes a training set/database to produce a classifier.
LSTM (Long Short-Term Memory)
A specialized recurrent neural network architecture, mentioned as automatically qualifying as "deep learning."
Machine Learning
An application of AI giving systems the ability to learn and improve from experience without being explicitly programmed.
Model Testing
The pipeline stage that validates a learned model, e.g. via cross-validation or bootstrap.
Preprocessing
Cleaning and standardizing raw data before it enters a model — noise filtering, feature extraction, normalization.
RNN (Recurrent Neural Network)
A specialized neural network architecture for sequential data, mentioned as automatically qualifying as "deep learning."
Supervised Learning
Learning a function that maps inputs to outputs from example input-output pairs (labeled training data).
Training Set / Database
The collection of labeled examples given to a learner to produce a classifier.

🚀 5-Minute Revision

  • ML = systems that learn from data instead of being explicitly programmed.
  • Supervised learning = learn input→output mapping from labeled example pairs.
  • Pipeline: real world → measuring devices → preprocessing → dimensionality reduction → model learning → model testing → results.
  • Database → Learner → Classifier is the simplified "training" view of the pipeline.
  • Deep Learning = ML subfield using brain-inspired algorithms (ANNs).
  • Traditional ML = handcrafted features. Deep learning = learned features, simple → intermediate → abstract.
  • Deep learning wins with lots of data; traditional ML can win with little data.
  • "How deep is deep?" — no single rule: CNN/RNN/LSTM automatically count; otherwise depth > 2 = deep, depth > 10 = very deep.

🧠 If You Remember Only One Thing...

Machine learning replaces hand-written rules with rules learned from data — and deep learning takes that one step further by letting the network learn its own features too, not just the final decision, stacking that learning across layers of increasing abstraction (edges → corners → object parts).
