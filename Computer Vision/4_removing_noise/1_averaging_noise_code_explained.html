02 — Creating the clean signal
true_signal = np.ones(100) * 90
what it does
np.ones(100) * 90
Makes an array of 100 nineties: [90, 90, 90, …]. A perfectly flat line — no noise, no variation.
Real-world analogy: A machine that should always output exactly 90°C. This is the ideal, perfect temperature.
03 — Normal Distribution (Adding Noise)
noise = np.random.normal(0, 10, 100) # mean=0 → centered at zero (noise doesn't push signal up/down) # std=10 → how spread/wild the noise is # size=100 → one noise value per signal point noisy_signal = true_signal + noise

Bell curve: mean=0, std=10 — 68% of noise falls between −10 and +10

concept
Normal Distribution
Most random values cluster around the center (mean). Fewer appear as you go further away. Looks like a bell when plotted.
Simple version: Throwing darts aiming at the center — most land near center, very few land far away. That clustering IS the normal distribution.
parameter
0 — mean
Center of the bell. Mean=0 means noise doesn't bias the signal up or down. Positives and negatives cancel out on average.
parameter
10 — standard deviation
Width of the bell — how wild the noise is. std=2 is gentle. std=10 is windy. std=30 is a storm. Drag the slider above to see.

05 — np.convolve — the main operation
smoothed_signal = np.convolve( noisy_signal, kernel, mode='same' )
concept
convolution — what it actually means
Convolution = slide a window across your data. At each position, it:

1. Looks at N values under the window
2. Multiplies each by a kernel weight
3. Sums them all up
4. Writes that ONE number as output
5. Moves one step right → repeat
Think of it like: You're walking along a noisy road. At each step, you look back at the last 5 houses and ask: "what was the average temperature?" That average is your smoothed value. Then you take one step forward and ask again.

ℹ mode explanation

mode='same' — You're plotting true_signal (100 values), noisy_signal (100 values), and smoothed_signal on the same graph. If smoothed_signal had 96 or 104 values, the x-axis positions wouldn't match and lines would be misaligned. mode='same' forces output to stay exactly 100 values.

Summary — the full picture

true_signal 100 nineties. The "ideal" signal with zero noise — perfectly flat at 90.
np.random.normal 100 random numbers from a bell curve centered at 0, spread ±10. This simulates noise.
noisy_signal true_signal + noise. A wiggly line that jiggles around 90.
kernel [0.2×5] Recipe of weights that add up to 1. Equal weights = simple average.
np.convolve Slides the kernel across the signal. At each position: multiply 5 values × weights, sum → write smoothed value.
mode='same' Output stays 100 values so all 3 lines align on the same graph.
end result smoothed_signal is calmer — closer to the true flat 90 line because random noise partially cancels out when averaged.
