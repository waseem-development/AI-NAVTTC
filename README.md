## 🧭 What is this?

This repository is my **living field journal** for the AI journey — a place where notes, experiments, notebooks, and datasets accumulate as I move through the landscape of Artificial Intelligence, from the ground up.

> *"Every expert was once a beginner. Every pro was once an amateur."*

The path ahead is long. This repo documents the walk.

---

## 🗺️ The Expedition Map

The learning journey is structured in **phases**. Each phase builds on the last — no skipping allowed.

```
FOUNDATION              CORE ML                DEEP LEARNING            BEYOND
──────────              ───────                ─────────────            ──────
  Python          →    NumPy / Pandas    →    Scikit-Learn       →    Neural Nets
  Syntax               Data Wrangling         Regression                TensorFlow
  OOP                  EDA & Viz              Classification            PyTorch
  File I/O             Data Cleaning          Clustering                CNNs / RNNs
  Libraries            Statistics             Model Evaluation          Transformers
                                                                        LLMs & Agents
```

> Phases don't have deadlines. They're done when they're *understood*, not when time runs out.

## 📚 Curriculum Overview

### Phase 1 — Python Foundations
> *The language of data science. Master this before anything else.*

| Topic | What's Covered |
|---|---|
| Syntax & Variables | Data types, operators, control flow |
| Functions & OOP | Reusable code, classes, modules |
| File I/O | Reading/writing files, working with formats |
| Standard Libraries | `os`, `sys`, `json`, `datetime`, and more |

---

### Phase 2 — Data Toolkit
> *The workbench. Where raw data becomes insight.*

| Library | Purpose |
|---|---|
| **NumPy** | Arrays, math operations, vectorization |
| **Pandas** | DataFrames, data cleaning, EDA, I/O |
| **Matplotlib** | Basic plotting and visualization |
| **Seaborn** | Statistical data visualization |

---

### Phase 3 — Machine Learning *(coming)*
> *Teaching machines to find patterns.*

- Supervised Learning — Regression & Classification
- Unsupervised Learning — Clustering, Dimensionality Reduction
- Model Evaluation — Metrics, cross-validation, overfitting
- `scikit-learn` end-to-end pipelines

---

### Phase 4 — Deep Learning *(coming)*
> *When patterns get complicated.*

- Neural Network fundamentals
- Frameworks: TensorFlow / PyTorch
- CNNs for images, RNNs for sequences
- Transfer Learning

---

### Phase 5 — Data Science & Specialization *(coming)*
> *Pulling it all together with real problems.*

- End-to-end DS projects
- Feature engineering
- Deployment basics
- NLP, Computer Vision, or Generative AI — TBD
