## &nbsp; 📚 &nbsp; Curriculum Overview

<details open>
<summary><b>🐍 &nbsp; Phase 1 — Python Foundations</b> &nbsp; <i>The language of data science.</i></summary>
<br>

| Standard Libraries | `os`, `sys`, `json`, `datetime`, and more |

<details open>

</details>

<br>

<details open>
